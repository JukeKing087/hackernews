Meridian Meridian is a web-browser for MacOS built on GPUI and Servo . Meridian is already quite useful to browse websites that are light on javascript and layouting features. The browser is highly configurable: fonts, keybinds, colors, tabs and all. To try Meridian, you can use nix: nix run git+https://tangled.org/oppi.li/meridian The project is developed on Tangled , all contributions are welcome, please do browse the list of open issues if you are looking to contribute! Meridian supports the following features: Address bar with typeahead Vertical and horizontal tabs Bookmarks and history Per-site zoom Audio and video playback Reader mode Tab previews Typeahead from bookmarks and history Context menu Dark mode Reader view Under the hood, Meridian is written in Rust and built on GPUI and Servo. Web pages and browser state is managed by Servo. The browser's chrome is drawn by gpui , the UI framework behind the Zed editor. The glue code to interface servo with gpui lives in separate lib
