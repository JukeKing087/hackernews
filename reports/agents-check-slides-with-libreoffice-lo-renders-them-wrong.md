When an AI agent edits a PowerPoint file, it wants to look at the result. It can’t open PowerPoint, so it turns each slide into a picture with LibreOffice and checks that picture. The trouble is that LibreOffice doesn’t draw slides the way PowerPoint does. Text comes out bigger. Lines sit lower. Shapes move. The agent ends up checking a picture that is not what people will see. It can fix problems that aren’t there and miss the ones that are. I’m building Folio, a tool that draws slides the way PowerPoint does, so agents see what people see.
