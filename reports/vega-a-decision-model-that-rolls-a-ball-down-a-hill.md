Vega is a decision model. You give it some text and a question whose answer type is fixed in advance, and it gives you back a value your code can use: one of your labels, a rating, or the probability that a statement is true. Each answer carries a calibrated probability, a set of answers it is prepared to stand behind, and a flag for the cases where it would rather not answer at all. The part that is unusual is how it gets there. Vega does not pick an answer by scoring words.
