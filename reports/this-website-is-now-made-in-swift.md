How this site is made, and why I love working on it. This website used to be made with Astro. Now it’s all Swift: every page, component, and style. The same language as my apps, and it feels a lot like SwiftUI. The browser still gets plain HTML and CSS, with a little JavaScript. What changed is how it’s made, and how much I enjoy working on it. Why Swift? I write Swift all day, and I love it. I no longer have to switch languages and tools when I go from an app to the website. But the real reason is the compiler. A website is lots of small things that need to agree: links, class names, styles, scripts, and the data of more than 60 apps. In a typical web stack, they only meet in the browser, and a mistake becomes a broken page
